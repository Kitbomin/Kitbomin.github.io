조약돌 놓기 (Pebble Sum)

3×n 표에 조약돌을 놓되 가로·세로로 인접하면 안 됩니다. 열마다 4가지 패턴(위 · 가운데 · 아래 · 위+아래) 중 하나를 고르고, peb[i][p] = w(i,p) + maxq 양립 peb[i-1][q] 로 최대 합을 구합니다.

행렬 경로 최소합

왼쪽 위에서 오른쪽 아래까지 오른쪽·아래로만 이동할 때 지나는 값의 최소합. c[i][j] = m[i][j] + min(c[i-1][j], c[i][j-1])

포팅하면서 고친 것

heap_sort.pde가 실제로는 선택 정렬

원인 파일 이름과 달리 selectionSorting()만 구현되어 있었음.

해결 최대 힙 구성 → 루트 추출 → sift-down 방식의 힙 정렬을 새로 구현.

퀵 정렬 선택 불가 · 병합 과정이 안 보임

원인 SortAnimation에서 퀵 정렬이 주석 처리, 병합 정렬은 분할 시점에만 상태를 저장해 병합 단계가 생략.

해결 모든 비교·쓰기 시점을 프레임으로 기록하고 비교/교환 횟수를 누적 표시.

BST 전위·후위 순회 미구현

원인 printTree()의 preorder / postorder 분기가 비어 있었음.

해결 세 가지 순회를 모두 구현하고 방문 순서를 노드 위에 번호로 애니메이션.

DP 예제의 정의·복잡도

원인 조약돌 패턴에 '위+아래'가 빠져 있었고, 행렬 경로는 메모 없는 재귀라 O(2n).

해결 교재 정의의 4패턴으로 수정, 행렬 경로는 표를 채우는 O(n²) 상향식 DP + 경로 역추적.
